4. Difference between HTML Tag, Element, and Attribute
1) HTML Tag
Tags are the angle-bracket markup symbols used to define webpage structure.
They are the syntax markers only.
Example: `<h1>` (opening tag), `</h1>` (closing tag)

2) HTML Element
An element is the **full complete unit**, including opening tag, inner content, and closing tag.
It represents one rendered object on the webpage.
Example:
`<h1>Campus Events Portal</h1>`

3) HTML Attribute
Attributes are 'property parameters' written inside the opening tag to modify element behaviour or information.
Example:
 `lang="en"` defines page language
 `href="URL"` defines link destination
`alt="description"` defines image alternative text
